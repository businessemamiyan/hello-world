# مهرداد — سرور

مغز دوم مهرداد: یه ربات تلگرام که همه‌چی (خرج، درآمد، ایده، کار، حس‌وحال) رو به‌خاطر می‌سپاره
و با لحن مناسب (پلنر/مربی/استاد/ایده‌پرداز/رفیق) جواب می‌ده. کاملاً جدا از پروژه قطب‌نما —
دیتابیس جدا، ربات تلگرام جدا، سرویس Docker جدا.

## فاز فعلی (۱)

- چت متنی تلگرام ✅
- حافظه بلندمدت (استخراج خودکار واقعیت‌ها از هر پیام) ✅
- لحن چندنقشی (پلنر/مربی/استاد/ایده‌پرداز/رفیق) ✅
- **سیستم عادت**: ساخت عادت (با یا بدون جایگزینی یک عادت بد)، استریک روزانه، یادآوری فعال شبانه
  با دکمه ✅/❌ (نه فقط صبر کردن تا خودت بگویی) ✅
- ویس (فرستادن/شنیدن صدا) — **فاز بعدی**، فعلاً پیام ویس رد می‌شود با توضیح
- اپ مستقل با دکمه ویس + دسترسی پیامک/نوتیفیکیشن — **فاز بعدی**

### سیستم عادت — چطور کار می‌کند
```
/habit هر روز ۲۰ دقیقه مطالعه              ← ساخت یک عادت تازه
/habit به‌جای سیگار وقتی استرس دارم، ۵ دقیقه نفس عمیق   ← عادت بد → جایگزین
/habits                                      ← لیست عادت‌های فعال + چک‌این امروز
```
هر شب در ساعت `HABIT_CHECKIN_TIME` (پیش‌فرض ۲۱:۰۰ به‌وقت تهران)، برای هر عادتی که آن روز
هنوز چک‌این نشده، یک پیام با دو دکمه فرستاده می‌شود. استریک روزهای پشت‌سرهم را می‌شمارد؛
یک روز از قلم‌افتادن استریک را صفر می‌کند (بدون جریمه‌ی اضافه — فردا دوباره از یک شروع می‌شود).
مهرداد خودش هم اگر وسط مکالمه‌ی عادی فهمید می‌خوای عادتی بسازی، همین دستور را پیشنهاد می‌دهد.

## چی لازم داری

1. یک **ربات تلگرام تازه** از [@BotFather](https://t.me/BotFather) (جدا از ربات قطب‌نما، اگر داری) → `BOT_TOKEN`
2. یک **کلید Anthropic API** از [console.anthropic.com](https://console.anthropic.com) → `ANTHROPIC_API_KEY`
   (این سرویس هزینه مصرفی (pay-as-you-go) دارد؛ بر اساس حجم پیام شارژ می‌شود.)
3. یک سرور با Docker (همون سروری که قطب‌نما رو هم روش بالا آوردی، یا هر سرور دیگه)

## نصب

```bash
git clone https://github.com/<owner>/hello-world.git
cd hello-world/mehrdad/server
./install.sh --install-docker   # اگر Docker نصب نیست
```

اسکریپت یک `.env` می‌سازد؛ `BOT_TOKEN` و `ANTHROPIC_API_KEY` را دستی توی آن پر کن، بعد دوباره
`./install.sh` را اجرا کن. بعد در تلگرام به ربات بنویس: `/start <SETUP_CODE از .env>`.

این نصب **افزایشی** است — با نام پروژه Compose جدا (`mehrdad`) کار می‌کند و هیچ سرویس دیگری
(ازجمله خود قطب‌نما، اگر روی همون سرور باشد) را لمس نمی‌کند.

## سرور خارج از ایران (مثلاً هلند)

پروکسی/Xray لازم نیست: `TELEGRAM_PROXY` و `ANTHROPIC_PROXY` را در `.env` خالی بگذار؛ `install.sh`
خودش بدون پروفایل `proxy` بالا می‌آید. فقط اگر سرور داخل ایران است، آن دو را به Xray وصل کن.

## حافظهٔ قدیمی (جست‌وجو)

در پرامپت فقط ۴۰ خاطرهٔ آخر می‌رود؛ برای بقیه، مغز خودش با ابزار `search_memory` در کل حافظه
(FTS5، نرمال‌سازی فارسی: ي/ك، نیم‌فاصله، ارقام) جست‌وجو می‌کند.

## چرا یک کلید API جدا از قطب‌نما؟

قطب‌نما عمداً **بدون هوش مصنوعی** ساخته شده بود (رفتار ربات قطب‌نما قانون‌محور است، نه مدل زبانی).
مهرداد برعکس — کاملاً حول یک مدل زبانی (Claude) ساخته شده، چون کارش فهمیدن زبان طبیعی و
نقش‌بازی‌کردن چندگانه است، نه فقط ثبت عدد.

## محدودیت‌های شناخته‌شده (فاز ۱)

- **تلگرام شخصی خودت** (چت‌هات با بقیه آدم‌ها) قابل‌خواندن نیست — API ربات تلگرام فقط پیام‌هایی
  که مستقیم به خود ربات فرستاده می‌شوند را می‌بیند. خوندن چت‌های شخصی بدون اطلاع طرف مقابل، هم
  از نظر تلگرام ممنوع است هم یک خط قرمز حریم خصوصی که رعایت می‌کنیم.
- ویس هنوز کار نمی‌کند (فاز ۲).
- فقط از تلگرام قابل‌دسترسی است؛ اپ مستقل فاز ۳ است.
