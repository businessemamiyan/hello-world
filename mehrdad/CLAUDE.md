# مهرداد — مغز دوم

## این چیه
یک دستیار مکالمه‌ای (نه داشبورد) که در تلگرام با کاربر چت می‌کند و همه‌چیز — خرج، درآمد، ایده،
کار، حس‌وحال — را به‌خاطر می‌سپارد. نقش ثابتی ندارد: بر اساس نیاز لحظه، پلنر/مربی/استاد/
ایده‌پرداز/رفیق می‌شود (همه در یک شخصیت واحد به اسم «مهرداد»).

**کاملاً جدا از پروژه `ghotbnama`** — دیتابیس جدا، ربات تلگرام جدا (باید توکن تازه از BotFather
بگیری)، سرویس Docker جدا با نام پروژه `mehrdad`. هیچ داده یا کدی بین این دو پروژه مشترک نیست.

## چرا هوش مصنوعی اینجا هست ولی در قطب‌نما نبود
قطب‌نما عمداً رفتار قانون‌محور (rule-based) دارد. مهرداد برعکس — کارش فهمیدن زبان طبیعی و
نقش‌بازی‌کردن چندگانه است، پس حول Claude (Anthropic API) ساخته شده: `server/app/brain.py`.

## فازها
1. ✅ چت متنی تلگرام + حافظه بلندمدت (استخراج خودکار واقعیت از هر پیام)
2. ⏳ ویس (فرستادن/شنیدن صدا) — هنوز نساخته شده
3. ⏳ اپ مستقل (چت + دکمه ویس + دسترسی پیامک/نوتیفیکیشن گوشی) — هنوز نساخته شده

## محدودیت دائمی، نه موقتی
API ربات تلگرام نمی‌تواند چت‌های شخصی کاربر با آدم‌های دیگر را بخواند — فقط پیام‌هایی که
مستقیم به خود ربات فرستاده می‌شوند دیده می‌شوند. این یک محدودیت پلتفرم تلگرام + یک خط قرمز
حریم‌خصوصی عمدی است، نه چیزی که در فاز بعدی حل شود.

## ساختار
```
mehrdad/
  server/
    app/
      config.py   تنظیمات از env
      memory.py   حافظه SQLite (owner, messages, memory)
      telegram.py کلاینت Bot API (همون الگوی قطب‌نما، عمداً تکرار شده نه import مشترک)
      brain.py     تماس با Claude + پرامپت شخصیت + استخراج JSON
      bot.py       حلقه‌ی long polling و مسیر پیام
      web.py       فقط /health
      main.py      اجرای همزمان وب + ربات
    tests/         pytest (حافظه، جریان ربات، پارس JSON مغز)
    install.sh     نصب افزایشی روی سرور (نام Compose project جدا: mehrdad)
```
