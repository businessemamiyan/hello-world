# قطب‌نمای درآمد — سیستم عامل شخصی

> **نسخه سرور** (ربات تلگرام، ثبت خودکار پیامک بانک، یادآوری‌های پیگیر، Mini App): [server/README.md](server/README.md)

اپ شخصی برای مدیریت **هدف → عدد → پروژه → اقدام → نتیجه → اندازه‌گیری → بازبینی → اصلاح**. یک فایل HTML، بدون سرور.

## بخش‌ها

| بخش | کار |
|---|---|
| خانه (داشبورد وضعیت من) | درآمد ماه در برابر هدف، فاصله، برآورد پایان ماه، سه سؤال «کجا هستم / مشکل اصلی / امروز چه کنم»، «واقعیت امروز من» (AI)، ۱۰ شاخص، نمودار ۶ ماه |
| مرکز فرمان | «الان مهم‌ترین مسئله من چیست؟» + امروز / هفته / ماه / فصل / درآمد / ریسک / فرصت + Focus Guard |
| امروز | حداکثر ۳ اقدام (درآمدساز، ساخت آینده، شخصی/یادگیری) با پیشنهاد از «اقدام بعدی» پروژه‌های فعال؛ ثبت نتیجه، زمان واقعی و دلیل انجام‌نشدن؛ بستن روز و امتیاز روز |
| اهداف | چشم‌انداز ۳ ساله + اهداف سالانه/فصلی/ماهانه/هفتگی؛ هدف بدون عدد و تاریخ پایان فقط «پیش‌نویس» است |
| پروژه‌ها | Backlog/Active/Paused/Completed/Cancelled، امتیازدهی ۵ معیاره و رتبه‌بندی ارزش |
| منابع درآمد | رشد نسبت به ماه قبل و میانگین ۶ ماه، سهم، روند، هزینه، ساعت، خالص هر ساعت، علامت بازبینی منبع بی‌درآمد (بدون حذف خودکار) |
| بازبینی هفتگی | عددهای خودکار هفته + سؤال‌های مدیریتی + گزارش مدیریتی AI |
| واقعیت بدون تعارف | ۸ سؤال با جواب عددی + جمع‌بندی هفتگی AI |
| پول و تراکنش‌ها | واریز/برداشت از پیامک بانک و تلگرام، هزینه به تفکیک دسته، جریان نقدی ۶ ماه، مانده حساب‌ها؛ واریزِ وصل‌شده به منبع درآمد به درآمد همان منبع اضافه می‌شود |
| مربی AI | ۹ دکمه آماده، سؤال آزاد با ادامه گفت‌وگو، «برنامه فردا» که مستقیم به روز فردا اضافه می‌شود |

## فرمول‌ها

- **ارزش پروژه (۰–۱۰۰):** درآمد ۳۵٪ + هدف اصلی ۲۵٪ + اهمیت ۱۵٪ + احتمال نتیجه ۱۵٪ + فوریت ۱۰٪. فوریت عمداً کمترین وزن را دارد.
- **ظرفیت پروژه فعال:** ساعت آزاد هفتگی ÷ ۶ (بین ۱ تا ۴).
- **امتیاز روز (۱۰۰):** اجرا ۲۵ · نتیجه ۳۵ (درآمد ثبت‌شده همان روز ۲۰ + نتیجه ثبت‌شده اقدام‌ها ۱۵) · تمرکز ۲۰ · نظم ثبت ۲۰.
- **امتیاز هفته (۱۰۰):** اجرا ۲۰ · درآمد نسبت به هدف هفتگی ۳۵ · پیشرفت پروژه‌ها ۱۵ · پیشرفت اهداف ۱۵ · تمرکز ۱۰ · نظم ۵.
- **روز مؤثر:** حداقل ۲ اقدام انجام‌شده یا درآمد ثبت‌شده.

## داده

- **Sample Data** فقط در حافظه ساخته می‌شود، ذخیره نمی‌شود و با داده واقعی قاطی نمی‌شود.
- داده واقعی در `localStorage` (و داخل Claude در پایگاه داده آرتیفکت) ذخیره می‌شود. از تنظیمات پشتیبان JSON بگیرید.
- داده نسخه ۱ خودکار منتقل می‌شود؛ داده نمونه نسخه ۱ و عددهای پیش‌فرض آن (مثل هدف ۱۰۰ میلیون) منتقل نمی‌شوند.
- مربی AI فقط وقتی اپ داخل Claude باز شود کار می‌کند.
