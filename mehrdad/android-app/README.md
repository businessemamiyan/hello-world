# اپ اندروید مهراد

دریچهٔ دوم مهراد (کنار تلگرام): چت متنی، ورودی صوتی گوشی، و ثبت خودکار پیامک/اعلان‌های **مالی**.
مغز و حافظه همان سرور است؛ اپ هیچ منطق هوشمندی ندارد.

## وصل‌شدن (جفت‌سازی)
۱. در تلگرام به مهراد: `/pair` ← کد ۸ حرفی (۱۰ دقیقه، یک‌بارمصرف).
۲. در اپ: آدرس https سرور + کد. اپ یک توکن اختصاصی همین گوشی می‌گیرد (رمز ثابتی جایی نیست).
۳. قطع یک گوشی: در تلگرام `/devices` و `/unpair <شماره>`.

## چه چیزی از گوشی بیرون می‌رود
- **پیامک**: فقط پیام‌هایی که مالی به نظر می‌رسند (واژه‌هایی مثل ریال/برداشت/واریز + عدد). فقط `RECEIVE_SMS`؛ صندوق پیامک خوانده نمی‌شود.
- **اعلان‌ها**: همان فیلتر مالی؛ باقی اعلان‌ها (پیام‌های دیگران، شبکه‌های اجتماعی) هرگز.
- **رمز یک‌بارمصرف/کد امنیتی/CVV2** هرگز ارسال نمی‌شود (اپ فیلتر می‌کند و سرور هم دوباره چک می‌کند).
- اگر اینترنت نبود، صف روی گوشی می‌ماند و بعداً خودکار ارسال می‌شود.

## ساخت
APK را GitHub Actions می‌سازد (`.github/workflows/mehrdad-android.yml`)؛ خروجی: artifact با نام `mehrdad-debug-apk`.
محلی: JDK 17 + Android SDK (platform 34) و `./gradlew assembleDebug`.

## بعداً
- پخش صوتی جواب (TTS فارسی گوشی‌ها ضعیف است؛ احتمالاً سمت سرور)
- انتخاب اپ‌های مجاز برای اعلان‌ها
- دسترسی به تقویم/مخاطبین/فایل‌ها با اجازهٔ جدا
