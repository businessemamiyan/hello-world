# اپ اندروید قطب‌نما

یک پوسته اندرویدی بومی (native، بدون Capacitor) که اپ وب قطب‌نما را در یک WebView باز می‌کند
و علاوه بر آن، پیامک‌های ورودی گوشی (برای ثبت خودکار پیامک بانک) را به سرور خودت می‌فرستد.

هیچ محتوایی داخل اپ بسته‌بندی نشده — همه‌چیز (شامل تم‌ها) از سرور خودت که با `server/install.sh`
بالا آورده‌ای می‌آید. یعنی این اپ صرفاً یک کلاینت جدید است، نه تغییری در سرور.

## ساخت APK

نیاز: JDK 17+، و Android SDK (فقط `platform-tools` + `platforms;android-34` + `build-tools;34.0.0`).

```bash
cd ghotbnama/android-app
echo "sdk.dir=/path/to/Android/sdk" > local.properties
./gradlew assembleDebug
```

خروجی: `app/build/outputs/apk/debug/app-debug.apk`

برای نسخه release (امضاشده، برای نصب دائمی روی گوشی خودت کافیست debug هم باشد؛ release فقط برای انتشار عمومی لازم است).

## نصب روی گوشی

1. فایل APK را به گوشی منتقل کن (تلگرام به خودت، لینک دانلود، یا کابل).
2. «نصب از منابع ناشناس» را برای همان اپ (مثلاً فایل‌منیجر یا تلگرام) فعال کن.
3. APK را نصب کن و باز کن.

## تنظیم اولیه (داخل خود اپ)

با اولین اجرا، دیالوگ «تنظیمات سرور» باز می‌شود و سه مقدار از تو می‌خواهد —
همه از فایل `ghotbnama/server/.env` سرورت کپی می‌شوند:

- **آدرس سرور**: باید با `https://` شروع شود (مثل `https://ghotb.example.ir`)
- **APP_KEY**: کلید ورود اپ
- **SMS_TOKEN**: توکن webhook پیامک

بعد از ذخیره، اپ مستقیم صفحه داشبورد قطب‌نما را از سرورت بار می‌کند.
این سه مقدار بعداً هم از منوی سه‌نقطه (⋮) → «تنظیمات سرور» قابل تغییرند —
بدون نیاز به نصب دوباره اپ، حتی اگر سرور را عوض کنی.

## دسترسی پیامک

بعد از باز شدن اپ، یک دیالوگ توضیح می‌دهد چرا دسترسی «خواندن پیامک» لازم است
(ثبت خودکار واریز/برداشت بانکی) و مجوز اندرویدی استاندارد را درخواست می‌کند.
اگر رد کنی، بقیه اپ عادی کار می‌کند؛ فقط ثبت خودکار پیامک غیرفعال می‌ماند —
هر وقت خواستی از «تنظیمات اندروید ← اپ‌ها ← قطب‌نما ← مجوزها» فعالش کن.

## نکته امنیتی

APK امضای debug دارد (برای نصب شخصی روی گوشی خودت کاملاً کافی است).
اگر خواستی آن را جایی منتشر کنی یا از فروشگاهی نصب شود، باید با یک keystore
واقعی امضا شود (`assembleRelease` + پیکربندی امضا) — فعلاً چون فقط برای
نصب شخصی روی گوشی خودت است نیازی به این مرحله نیست.
