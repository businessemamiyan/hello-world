# سرور قطب‌نما — ربات تلگرام، پیامک بانک، Mini App

```
پیامک بانک (اندروید) ──HTTPS──► /sms/<SMS_TOKEN> ─┐
پیام تو در تلگرام ◄──long polling از طریق پروکسی──► ربات ─┼─► SQLite (یک فایل در ./data)
اپ (Mini App داخل تلگرام یا مرورگر) ──► /api/state ───────┘
یادآوری‌ها: ۰۷:۳۰ برنامه · ۱۳:۰۰ نیمه روز · ۲۱:۰۰ بستن روز (+ دو یادآوری) · جمعه ۱۹:۰۰ بازبینی
```

- **بدون هوش مصنوعی**: خواندن پیامک و پیام‌ها فقط با قواعد ثابت است. مربی AI فقط در نسخه داخل Claude هست.
- **سرور ایران**: پیامک‌ها مستقیم از گوشی به سرور تهران می‌رسند (حتی وقت قطعی اینترنت بین‌الملل). ربات برای رسیدن به تلگرام از پروکسی استفاده می‌کند و webhook ورودی لازم ندارد.
- اگر تلگرام موقتاً در دسترس نباشد، داده‌ها ثبت می‌شوند و اعلان‌ها بعد از وصل شدن فرستاده می‌شوند.

## ۱. ساخت ربات
1. در تلگرام به `@BotFather` پیام بده ← `/newbot` ← توکن را نگه دار.
2. (اختیاری) شناسه عددی خودت را از `@userinfobot` بگیر و در `OWNER_ID` بگذار. اگر نگذاری، با `SETUP_CODE` معرفی می‌شوی.

## ۲. آماده‌سازی سرور تهران
```bash
git clone <این ریپو> && cd hello-world/ghotbnama/server
cp .env.example .env
openssl rand -hex 24   # برای SMS_TOKEN
openssl rand -hex 24   # برای APP_KEY
openssl rand -hex 6    # برای SETUP_CODE
nano .env              # مقادیر را پر کن
```
- **Docker Hub** از IPهای ایران معمولاً مسدود است. یک registry mirror داخلی (مثل mirror آروان‌کلاد یا هر mirror که الان در دسترس است) را در `/etc/docker/daemon.json` تنظیم کن، یا `BASE_IMAGE`، `XRAY_IMAGE` و `CADDY_IMAGE` را در `.env` به آدرس mirror بده.
- اگر PyPI کند یا مسدود بود، `PIP_INDEX_URL` را در `.env` به یک mirror PyPI بده.

## ۳. رسیدن به تلگرام (پروکسی)
API تلگرام از ایران فیلتر است. ساده‌ترین راه، همان سرور relay نواتونل است:
```bash
mkdir -p xray && cp xray/config.example.json xray/config.json
nano xray/config.json   # SERVER_ADDRESS, UUID, PUBLIC_KEY, SHORT_ID, SNI_DOMAIN را از کانفیگ VLESS+Reality خودت بگذار
```
یک کاربر جدا در Marzban برای این سرور بساز تا ترافیکش از مشتری‌ها جدا باشد. در `.env`: `TELEGRAM_PROXY=socks5://xray:10808`.

## ۴. HTTPS برای Mini App
تلگرام Mini App را فقط با آدرس HTTPS باز می‌کند. دو راه:
- **Caddy + Let's Encrypt** (پروفایل `https`): دامنه را به IP سرور بده و `DOMAIN` را پر کن. اگر دریافت گواهی به‌خاطر محدودیت ورودی بین‌الملل سرور ایران شکست خورد، راه دوم را برو.
- **CDN داخلی** (مثلاً آروان‌کلاد) با SSL خودش جلوی پورت 8080. در این حالت پورت 8080 را روی 127.0.0.1 نگذار یا یک reverse proxy جلویش قرار بده.

## ۵. اجرا
راه سریع (مراحل ۲ و این مرحله را با هم انجام می‌دهد؛ فقط همین سرویس را در یک پروژه Docker جدا به نام `ghotbnama` بالا می‌آورد، به هیچ کانتینر/سرویس دیگری روی سرور دست نمی‌زند):
```bash
./install.sh                  # اگر Docker از قبل نصب است
./install.sh --install-docker # اگر Docker نیست و می‌خواهی همین‌جا نصب شود
```
دستی:
```bash
docker compose --profile proxy up -d --build              # بدون Caddy
docker compose --profile proxy --profile https up -d --build
curl http://127.0.0.1:8080/health
```
`telegram_last_ok_seconds_ago` باید عدد کوچکی باشد. اگر `null` ماند، پروکسی کار نمی‌کند: `docker compose logs ghotbnama xray`.

بعد در تلگرام به ربات بنویس: `/start <SETUP_CODE>` ← از این لحظه ربات فقط به تو جواب می‌دهد.
دکمه «📱 اپ» یا منوی پایین چت، اپ را داخل تلگرام باز می‌کند. در مرورگر: `https://دامنه/app?key=APP_KEY` (فقط یک بار؛ کلید در مرورگر ذخیره می‌شود).

## ۶. فوروارد پیامک بانک از اندروید
**روش ۱ — اپ متن‌باز «SMS to URL Forwarder»** (F-Droid / Google Play):
1. «Add forwarding» ← Sender: شماره یا نام فرستنده پیامک هر بانک (مثل `+98700…` یا `Bank Mellat`)؛ برای هر بانک یک قانون.
2. URL: `https://دامنه/sms/<SMS_TOKEN>`
3. JSON template: `{"from":"%from%","text":"%text%"}`
4. در تنظیمات اندروید، «بهینه‌سازی باتری» را برای این اپ خاموش کن، وگرنه بعد از مدتی کار نمی‌کند.

**روش ۲ — MacroDroid**: Trigger «SMS Received» (فقط از شماره‌های بانک) ← Action «HTTP Request»: POST به همان URL، Body از نوع JSON: `{"from":"[sms_number]","text":"[sms_message]"}`.

تست: `curl -X POST https://دامنه/sms/<SMS_TOKEN> -H 'content-type: application/json' -d '{"from":"test","text":"بانك ملت\nبرداشت:125,000\nمانده:4,560,000"}'` ← ربات باید پیام «💳 پیامک بانک: هزینه ۱۲٬۵۰۰ تومان» بفرستد.

## کار روزانه با ربات
| چه می‌نویسی | چه می‌شود |
|---|---|
| `۲۵۰ ناهار` | هزینه ۲۵۰ هزار تومان، دسته «خوراک» (عدد ۱۰ تا ۹۹۹ بدون واحد = هزار تومان) |
| `۲ تومن مکانیک` | هزینه ۲ میلیون (عدد زیر ۱۰ = میلیون). برداشت ربات نمایش داده می‌شود و با دکمه ×۱۰۰۰/÷۱۰۰۰ اصلاح می‌شود |
| `دیروز ۱.۵ میلیون قسط` | هزینه با تاریخ دیروز |
| `+۳۲ میلیون حقوق` | واریز؛ ربات می‌پرسد مال کدام منبع درآمد است و به درآمد همان منبع در اپ اضافه می‌کند |
| `/plan` | ۳ اقدام امروز؛ پیشنهادها از «اقدام بعدی» پروژه‌های فعال. `... ۹۰د` یعنی ۹۰ دقیقه تخمین |
| دکمه ✅ ◐ ❌ | نتیجه، زمان و دلیل انجام‌نشدن را می‌پرسد؛ وقتی همه ثبت شد روز بسته و امتیاز داده می‌شود |
| `/money` `/week` `/today` | گزارش پول ماه، هفته، امروز |
| `/export` | دو فایل: پشتیبان کامل و نسخه سبک برای اپ داخل Claude (تنظیمات ← بازگردانی از فایل) |
| فرستادن فایل JSON به ربات | جایگزینی داده سرور (با تأیید) |

**پیگیری**: صبح اگر برنامه نچیدی، ۲ و ۴ ساعت بعد دوباره می‌پرسد. شب اگر روز را نبستی، ۱ و ۲ ساعت بعد دوباره می‌پرسد و تعداد روزهای بسته‌نشده هفته را جلویت می‌گذارد. `/snooze` فقط یادآوری‌های تکمیلی را ۱ ساعت عقب می‌اندازد؛ خاموش کردن کامل عمداً وجود ندارد.

## محدودیت‌ها (صادقانه)
- **قالب پیامک بانک‌ها**: پارسر قالب‌های رایج ملت، ملی، صادرات، تجارت، پاسارگاد، سامان، بلو، رسالت و… را پوشش می‌دهد (تست‌ها: `tests/test_parsers.py`). بانکی که قالبش فرق کند، پیامکش با برچسب «نتوانستم بخوانم» برایت فرستاده می‌شود (شماره‌های بلند ماسک می‌شوند). نمونه ماسک‌شده‌اش را بفرست تا قاعده‌اش اضافه شود.
- **دوباره‌شماری حقوق**: اگر حقوق این ماه را در اپ دستی وارد کرده‌ای و پیامک واریزش را هم به «حقوق» وصل کنی، دو بار حساب می‌شود. از این به بعد فقط یکی را استفاده کن (پیشنهاد: پیامک).
- **همزمانی**: اگر در همان چند ثانیه‌ای که در اپ چیزی را ویرایش می‌کنی پیامکی برسد، اپ آخرین تغییرت را ذخیره نمی‌کند و می‌گوید دوباره انجامش بده (داده ربات هرگز بی‌صدا رونویسی نمی‌شود).
- **داده مالی**: همه‌چیز در `./data/ghotbnama.db` روی سرور تهران است. از این پوشه نسخه پشتیبان بگیر و دسترسی SSH سرور را محدود کن.
