# قطب‌نمای درآمد

اپ شخصی برای برنامه‌ریزی اهداف و رسیدن به درآمد بالاتر. یک فایل HTML، بدون نیاز به سرور.

- **امروز:** حداکثر ۳ کار مهم روزانه، کارهای ناتمام به روز بعد منتقل می‌شوند، نمودار پیوستگی ۲۱ روزه.
- **هشدارهای صادقانه:** شکاف تا هدف ماهانه، وابستگی به حقوق، پخش شدن تمرکز، منابع با درآمد صفر، هدف بدون عدد یا مهلت.
- **اهداف:** چشم‌انداز + اهداف سالانه/فصلی/ماهانه با عدد، مهلت شمسی و قدم‌های اجرایی.
- **منابع درآمد:** نمودار ۶ ماه اخیر و جدول ماهانه قابل ویرایش.
- **بازبینی هفتگی:** چه کردم، نتیجه با عدد، چه جواب نداد، درس، تمرکز هفته بعد.
- **مربی هوش مصنوعی:** فقط وقتی داخل Claude باز شود کار می‌کند.

داده‌ها در `localStorage` مرورگر ذخیره می‌شوند؛ از تب تنظیمات پشتیبان JSON بگیرید.
